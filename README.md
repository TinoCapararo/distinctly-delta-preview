# Distinctly Delta — Wear, Pair & Care

Static responsive website built from the Figma project. Works on GitHub Pages without dependencies or build steps.

## Publish
1. Upload `index.html`, `styles.css`, `script.js`, and the `assets/` directory to the root of a GitHub repository.
2. Open repository **Settings → Pages → Build and deployment → Deploy from a branch**, select `main` and `/ (root)` and save.
3. Your site will be available at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.
4. The QR code should point to the permanent published URL. Choose the final repository name before printing the QR.
